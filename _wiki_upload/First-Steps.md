# First steps

1. **Just write.** Talk to Naby in the window as you would to a person. It learns from every message.
2. **Give it work.** Need something done (summarize a document, find something, make a file)? Just ask. Naby picks suitable models (desktop apps, free web chats or your API keys) and returns one finished answer.
3. **Rate answers.** 👍 means “answer like this”, 👎 means “not that”. This is how Naby learns your style and which model to trust for each topic.
4. **Add keys (optional).** Keys for ChatGPT, Claude, GigaChat and other models make answers stronger. Go to ⚙ Settings → “Neural networks and apps”, or paste a key into the chat: Naby hides and checks it. Naby also works without keys.
5. **Choose the depth.** The switch next to the input box: ⚡ quick, ◎ normal, 🔬 deep (build 49).

## Where things are in the window

- **Left:** your conversations grouped by **project**, plus 📌 pinned and 🗄 archive (build 49). At the bottom: 🔄 Update, 💼 Professions, ❓ Help, 🏠 Smart home, ⚙ Settings, 📁 Folder, ⌨ Commands, 🐞 Bug report.
- **Right:** a panel with Naby's live browser, files, results, live page preview and the progress of the current task.
- **Top right:** ✎ instruction for this conversation (role, style, language), ⇣ save the conversation, ☾ theme, ⌨ commands, ? help.
- Every setting has an **“i”** icon with a plain explanation.

## Useful shortcuts

| Keys | Action |
|---|---|
| Esc | Stop the answer or task |
| Ctrl+N | New conversation |
| Ctrl+K | Search conversations |
| Ctrl+V | Paste a file or screenshot |
| Ctrl+Alt+Space | Call Naby from any program on Windows (build 49) |

## While Naby is working

- A new message in the same conversation **corrects the running task** (“better in Excel”, “only October”), and Naby changes course without starting over (build 42).
- Need a separate task in parallel? Start with “new task: …”.
- “stop” or Esc stops the work.
