# Commands

You can always just **describe what you want in your own words**, and Naby will understand. The short commands below are shortcuts. The full list is in the app under **⌨ Commands**. Naby's built-in keywords are in Russian, so the Russian form is given next to each English one; both work as plain requests.

| What you want | Say (English) | По-русски |
|---|---|---|
| Remember a fact | remember: … | запомни: … |
| Deep research with sources | research: … | исследуй: … |
| Pick the best local model | speed test | тест скорости |
| Make the local model faster | speed up the model | ускорь модель |
| Use more or less of the PC | power 50 | мощность 50 |
| Install a small local model | install lfm3 · install lfm3 vision | поставь lfm3 · поставь lfm3 зрение |
| Search your folders | index folder C:\Docs · find in folders … | проиндексируй папку … · найди в папках … |
| Check a document | check document … | проверь документ … |
| Summarize a video | summarize video <link or file> | перескажи видео <ссылка или файл> |
| Teach Naby by showing | I'll show you how to … → done | покажу, как делать … → готово |
| Your writing style | my style · forget my style | мой стиль · забудь мой стиль |
| Deleted items | trash · restore <number> | корзина · верни <номер> |
| What Naby did today | what did you do today · undo <number> | что ты делал сегодня · откати <номер> |
| Standing assignment | assignment: … daily at 9:00 · assignments | поручение: … ежедневно в 9:00 · поручения |
| Helpers | helpers · stop helpers | помощники · стоп помощникам |
| Other agents (A2A) | give access to agent <name> · revoke access <name> · agents log | выдай доступ агенту <имя> · отзови доступ <имя> · журнал агентов |
| Sign in to a website | help me sign in · press it for me · signed in | помоги войти · нажми за меня · вошёл |
| Install a community profession | install profession <GitHub link> | установи профессию <ссылка> |
| Community professions | community professions · remove profession <id> | профессии сообщества · удали профессию <id> |
| Check a skill before installing | check skill <link> | проверь навык <ссылка> |
| Report a problem | bug report · self-check | отчёт об ошибке · самопроверка |
| License | license (paste the number to activate) | лицензия |
| Naby's laws | laws | законы |
| Quick entry key | quick entry ctrl+shift+space · turn off quick entry | быстрый вызов … · выключи быстрый вызов |
| Correct a running task | just write the correction | просто напишите поправку |
| Stop | stop or Esc | стоп или Esc |

## Keyboard

| Keys | Action |
|---|---|
| Esc | Stop |
| Ctrl+N | New conversation |
| Ctrl+K | Search conversations |
| Ctrl+Alt+Space | Call Naby from any program (Windows) |
