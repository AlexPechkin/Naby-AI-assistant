# Совместимость с российскими ОС

Проверка Naby на ALT Linux, Astra Linux и РЕД ОС в контейнерах официальных образов (запуск вручную во вкладке Actions →
«Совместимость с российскими ОС»): официальный установщик с сайта → встроенный Python → импорт модулей оболочки →
Tk на виртуальном дисплее → пакеты профессий без сети → запуск программы на 25 секунд без ошибок.
Протоколы — в артефактах запуска (`compat-<ос>.json`, лог) и в сводке запуска.

Проверка в контейнере подтверждает установку и запуск; полная проверка на рабочей станции с графическим окружением
(Fly, KDE, GNOME) выполняется перед подачей протоколов вендорам.
